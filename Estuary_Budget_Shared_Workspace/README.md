# Estuary SCHISM-AED Budget Analysis Working Space

Shared working space for the Spoon Estuary and Pioneer River SCHISM-AED models, budget-analysis scripts, and supporting documentation.

## Repository structure

- `Spoon_Model/` — updated Spoon Estuary model setup and notes.
- `Pioneer_Model/` — updated Pioneer River model setup and notes.
- `Budget_Analysis/` — Python scripts used to implement Water, Salt/Heat and TN budget calculations.
- `Documents/` — calculation-framework PowerPoint and detailed methodology report.
- `In_Progress/` — ongoing work and daily progress notes. Completed and verified material can be moved to the appropriate folder above.

Large raw model outputs should remain on the project storage/HPC unless there is a specific reason to share them through GitHub.
